## Pinouts 
Pin 2 -> Input -> Controls LED 1
Pin 3 -> Input -> Controls LED 2

## Circuits
Task 1: Connected the LED’s short leg to GND and its long leg positive side to the 330-ohm resistor. Then, connect the other leg of the resistor to a wire that connects to Vcc.  
 
Task 2:  Used one 330-ohm resistor and connected the short legs of the LED on one row because there had been a single resistor. Connected the designated pins, pin 8 and pin 9 to the long leg of the LEDs. GND is connected to the resistor’s other leg using a wire 

## Build it in VSCode 
- Open the PlatformIO extension in VSCode or ArduinonIDE
- Connect the Arduino Uno with a USB cable and select the proper settings
- Select Build and Upload in the platform
